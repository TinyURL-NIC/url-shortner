## My Thoughts

### Dashboard

One thing I felt while building it is that we probably don't need a separate **My Links** page.

Instead, the **Dashboard** itself can show:

* All the links created by the user.
* Which links are active and which are expired.
* On clicking any link card, the user can navigate to that link's dedicated **Analytics** page.

It felt like a cleaner and simpler flow to me.

### Backend Integration

I'd really appreciate it if the backend team could take care of the API integration. I don't have much experience with that part yet, so I feel it'd be better handled by someone who's more familiar with it.

The UI is ready from my side, and of course, feel free to make any changes wherever you think they're needed.

### About Page

I added the **About** link in the landing page navigation, although the page itself hasn't been created yet.

I thought it would be nice if it became a simple **Meet the Team** page where we introduce everyone who worked on the project.

### Landing Page Input

For the input box on the landing page, what I had in mind was:

* **If the user is logged in:** Open the **Create Link** modal.
* **If the user isn't logged in:** Redirect them to the **Sign In** page.
